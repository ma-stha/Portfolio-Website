placeholder for any file that is missing, so nothing breaks while you gather them.

|-------------------|-------------------------------------------|----------------|

| case-local.jpg    | Case study 2 cover                        | 1600 × 1000 px |
| case-saas.jpg     | Case study 3 cover                        | 1600 × 1000 px |
| case-email.jpg    | Case study 4 cover                        | 1600 × 1000 px |
| og-image.png      | Link preview (already generated, replace) | 1200 × 630 px  |
