# mastha — Manjil Shrestha Portfolio

Personal site for a data-driven digital marketer in Melbourne. Target keyword: **Digital Marketing Expert in Melbourne**.

Zero build step. Plain HTML, CSS and JavaScript, so it runs on any host (cPanel, Netlify, Vercel, GitHub Pages).

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Concept: "Ultraviolet"

Near-black textured paper, one violet light. The cursor is a UV torch: it lights the paper and reveals ink that is otherwise invisible.

- **Hidden notes**: seven handwritten notes across the page only appear under the torch. A counter in the bottom-left tracks how many a visitor has found, with a reward when they find all seven.
- **Hero photo**: shown as a violet duotone. Under the torch it reveals the full-colour photo.
- **Case files**: results are redacted. Resting the torch on the numbers declassifies the file with a stamp. On phones, files declassify as they scroll into view.
- **Touch devices**: the torch wanders through the hero by itself, and follows the visitor's finger anywhere on the page.
- **Accessibility**: a "Reveal all" button shows every hidden element. Reduced-motion users get everything revealed by default.

Home page sections: client marquee, about with stats, services accordion, growth lab calculator, typing terminal process, toolkit, experience timeline with education and certifications, testimonial slider, insights, FAQ (published as FAQ schema), contact card and form, and a footer logo that lights up under the torch.

## Where to edit things

| What | File |
|------|------|
| Home page content: email, socials, clients, stats, services, case files, process, calculator defaults, toolkit, experience, education, certifications, testimonials, insights, FAQ | `js/content.js` |
| Home hero, About text, hidden notes, meta tags | `index.html` |
| Services, pricing, booking, contact copy | `services/index.html`, `book/index.html`, `contact/index.html` |
| Booking hours and how far ahead people can book | top of `js/book.js` (`SLOTS`, `DAYS_AHEAD`) |
| Colours, fonts, torch size | `css/styles.css` (tokens at the top); inner pages also use `css/pages.css` |
| Photos | `assets/img/` (see the README there) |

The nav and footer are repeated in each page's HTML. If you add a nav link, add it to every page.

Scripts: `core.js` runs on every page (torch, nav, forms). `home.js`, `pages.js`, `book.js` and `blog.js` are page-specific.

## Writing a blog post

1. Copy `blog/_template/` to `blog/your-post-slug/`.
2. In the new `index.html`, replace every `_template` reference in the `<head>`, then update the title, description and the BlogPosting JSON-LD. Remove the `noindex` robots tag.
3. Write the article inside `<div class="prose">`. Give every `h2` an `id`; the table of contents builds itself.
4. Add a card to `blog/index.html` (copy an existing `<a class="post">` card), plus an entry in `sitemap.xml` and `blog/feed.xml`.
5. Optional: add the post to `insights` in `js/content.js` so it shows on the home page.

## Adding another service page

The inner pages are generated by `tools/build_pages.py` (shared layout, nav, footer, SEO tags). The SEO page lives in `tools/service_seo.py`.

1. Copy `tools/service_seo.py` to e.g. `tools/service_paid.py`, rename the function and change `path`, copy, pricing and FAQs.
2. In `tools/build_pages.py`, `exec` the new file next to the SEO one, call the function, and add the URL to `sitemap()`.
3. Run `python3 tools/build_pages.py`. It rewrites every generated page, so make copy edits in the `tools/` files rather than the HTML.
4. On `/services/`, the "Explore … in depth" button is added in `services_page()` (search for `svcx__deep`).

## Before launch

- Replace everything marked **DEMO** in `js/content.js`, plus demo prices and testimonials on the inner pages.
- Replace `YOUR_FORM_ID` with a Formspree form id in every form (home, contact, book, blog newsletters). Until then forms open the visitor's email app.
- Add `assets/Manjil-Shrestha-CV.pdf` or remove the "Download CV" links.
- Optional: set `calendlyUrl` in `js/content.js` to replace the built-in booking widget with a Calendly embed.

## Brand

- **Logo**: `assets/mastha-logo.svg` (light), `mastha-logo-dark.svg`, `mastha-logo-violet.svg`. Traced as an exact vector from the supplied artwork and inlined as an SVG symbol.
- **Favicon / app icons**: generated from the violet-ring avatar (`assets/favicon-32.png`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`).
- **Palette**: paper `#141317`, ink `#ECE8F4`, violet `#7844E9` (sampled from the avatar ring), UV glow `#B596FF`.
- **Type**: Geist (UI and headlines), Geist Mono (data), Pirata One (blackletter accents that match the logo), Caveat (the hidden handwriting).
- The earlier MANJIL logo files are kept in `assets/brand/`.

## Deploy

- **GitHub Pages**: enable Settings → Pages → Source "GitHub Actions". `.github/workflows/deploy-pages.yml` publishes on every push to `main`.
- **Any other host**: upload the repository contents as-is.

Update the canonical URL in `index.html`, `sitemap.xml` and `robots.txt` if the domain changes.
